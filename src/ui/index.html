      Workflow template
      
        
      
      
      
      
        
      
          Use a template for repeatable work with clear checkpoints, such as
          research followed by review. Each step starts only after the previous
          step succeeds.
        
      
        
      
          
        
      
        
        
      
          
      Ordered steps
      
          
        
      
        
      
          Use {{input.topic}} for an input and {{steps.research}} for the output
          of an earlier step. Profiles set the model and limits. Tools follow
          the running worker's configuration.
        
      
        
      
        
      
        
      
          Edits affect future runs. Existing runs keep their original
            definition.
